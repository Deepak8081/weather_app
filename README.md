# 🌤️ SkyCast — Real-Time Weather Forecast Dashboard

[![Vite](https://img.shields.io/badge/Vite-5.x-646CFF?logo=vite&logoColor=white)](https://vitejs.dev/)

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A sleek, responsive **Weather Forecast Web Application** built with React and Vite. Delivers real-time meteorological conditions, temperature, humidity, wind velocity, and multi-day forecasts for any city worldwide using live weather APIs.

---

## ✨ Key Features
- **Instant City Search**: Search current weather for any global location with autocomplete suggestions.
- **Detailed Weather Metrics**: Real-feel temperature, humidity percentages, wind speed, atmospheric pressure, and UV index.
- **Dynamic Weather Visuals**: Animated icons reflecting sunny, rainy, cloudy, or snowy conditions.
- **Responsive Layout**: Designed for optimal viewing on desktop screens, tablets, and smartphones.

---

## 🚀 Setup & Execution
```bash
npm install
npm run dev
```
